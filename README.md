# Moye Notes

Handwrite and highlight on PDFs, then export annotated copies. Create handwritten notebooks in the same Obsidian vault. Moye Notes Free works offline and is free to use without an account or activation.

[中文介绍](#中文介绍)

## PDF annotation

- Write and highlight with the ballpoint pen and highlighter. Use the eraser, ruler, or image insertion as needed.
- Find and select text, and navigate with the outline and page thumbnails. Moye remembers the last page opened on this device.
- Show or hide your annotations, or export them in a new PDF. Your annotations are saved alongside the original PDF, which stays intact.

## Handwritten notebooks

- Choose blank, grid, or dotted paper. Browse a single page, a spread, or a vertical stack.
- Use the basic ballpoint pen, hold to shape, and switch between freehand and straight-line highlighting.
- Find and favorite notebooks in the Moye library. Export notebooks as PDF and recover copies from local backups.

## Get started

1. In Obsidian, open **Settings → Community plugins → Browse**. Search for **Moye Notes**, then install and enable it once it is listed.
2. Open a PDF in your vault. Choose the Moye annotation icon in its header or run **Open current PDF in Moye** from the command palette.
3. Run **Open the Moye library**, then select **New** to create a notebook. Moye settings let you choose save locations and switch to Simplified Chinese.

Requires Obsidian 1.15.1 or later. PDF rendering on iPhone and iPad requires iOS or iPadOS 18 or later. JPEG 2000 decoding is included and works offline.

## Files and privacy

Notebooks, PDF annotations, and their attached images are stored in your vault. Keep the original PDF, its companion annotation file, and any attached images together when backing up or moving a PDF. Automatic recovery backups stay in Obsidian's local storage on the current device.

Moye Notes Free has no telemetry or account requirement. Writing, PDF rendering, search, and export work offline. You can use the system file picker to insert an image from outside your vault. Support links open your browser or email app when you select them. The **Unlock Full Version** settings page contains information about Moye Notes Pro.

## Optional paid edition

Moye Notes Pro is an optional, separately installed paid edition. It adds pressure-sensitive pens, advanced PDF annotation and excerpt collection, handwriting recognition and cleanup, and more notebook tools. Some Pro features require a resource download or a configured AI service.

With Moye Notes Pro 0.4.6, you can handwrite and highlight directly on existing Markdown notes, collect excerpts, jump back to the source passage, and export annotated Markdown as a PDF.

You can keep using Free without buying Pro. Before switching to Pro, disable Free in the same vault.
